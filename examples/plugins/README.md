# Toy file API examples

These two standard-library scripts are developer samples, not plugin packages.
They import no Operon code and have no third-party dependencies. The analysis
sample emits external QC TSV, events and derived FASTA; a supplied `--job-id`
also makes its JSON output an `import-hits` payload. The visualization sample
verifies bundle checksums and draws a small SVG.

Follow `docs/en/reference/plugin-examples.md` or its Chinese counterpart.
